## Technologies and Frameworks Used

The Phase 1 implementation also uses the following technologies:

- **Mininet** – Network emulation and topology testing
- **Open vSwitch (OVS)** – Software-based OpenFlow switches
- **OS-Ken** – SDN controller framework
- **OpenFlow 1.3** – Southbound communication protocol
- **iPerf3** – TCP and UDP traffic generation
- **Scapy** – Packet generation for IoT/anomaly traffic
- **PyTorch** – AI/ML framework for the planned LSTM traffic prediction
- **Tailscale** – Secure mesh connectivity between isolated environments
